# CurlyArrows chemical analysis
CurlyArrows is a program for assessing organic chemistry reaction mechanisms with curly arrows and accompanying student reasoning. It analyzes both the drawn mechanism and the written explanation provided by the student.

The program compares ChemDoodle JSON code of a student-drawn reaction mechanism with a model mechanism linked to the selected exercise. In parallel, it evaluates the student’s written reasoning against a list of expected concept tags for each step. These two analyses are then integrated to generate structured feedback on both the correctness of the mechanism and the quality of the student’s chemical reasoning.

Feedback is provided at three levels:
- **Global level**: Understanding of the overall reaction pathway and reaction steps
- **Mechanistic level**: Evaluation of curly arrow use and electron-flow logic
- **Structural level**: Evaluation of molecular structures of intermediates, and products

The program is incorporated in the CurlyArrows webpage.

## Features
- Compares and aligns student-provided reaction mechanisms with model mechanisms
- Detects errors in individual reaction steps and the electron flow (curly arrows)
- Identifies incorrect molecular structures and names them (https://pubchem.ncbi.nlm.nih.gov/rest/pug/compound/smiles/{canonical_smiles}/property/Title/JSON)
- Assesses student reasoning with openAI
- Provides structured teacher feedback with openAI

## Operating
The program is operated via operate_analysis.py

### Input
1. JSON file generated by ChemDoodle based on a chemical reaction mechanism
2. student reasoning
3. exercise number
4. OpenAI API_key

### Expected Output
A text report providing structured feedback on the mechanism and reasoning, including global reaction step analysis, mechanistic curly arrow evaluation, and structural assessment.

## Data Structure
The program relies on a CSV file that stores model answers:
- `exersice_model_answers.csv`: Contains JSON representations of model mechanisms, with the second row corresponding to exercise 1, the third row to exercise 2, and so on.
- `reaction_concept_tags`: Contains information to assess the student reasoning on the chemical reaction mechanism.
