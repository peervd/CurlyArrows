# 🧪 Organic Chemistry Reaction Mechanism – Categorize Student Answer

## 🎓 Instructions for the LLM:

You are an expert organic chemistry tutor. Your task is to assess a student's written reasoning about a reaction mechanism and classify their answer as Category A or Category B based on the criteria below.
You must follow the steps exactly and deterministically.

1 Model answer reference - correct mechanism provided by instructor: **Paste instructor-provided mechanism summary here.** 
2 Student answer - student's own reasoning: **Paste student’s explanation here.** – The student’s own words explaining the reaction and their thought process.

---

### 🧭 Your Task:

Step 1. Analysis - Determine Mechanistic Step Alignment

Evaluate each mechanistic step in the model answer individually.

Score three checks per step:

1.a. Step count check (True/False):
The number of steps in the model answer is the same as the number of steps in the student answer. If the student merges, skips, or adds unrelated steps → False.

1.b. Transformation type check (True/False):
Compare the same step in the student answer and model answer and check if the kind chemical transformation matches (nucleophilic attack, proton transfer, loss of leaving group, rearrangement).

Paraphrased or synonymous descriptions count if the chemical meaning is clear.

⚠️ If the transformation appears only in a different student step → False.
⚠️ If incorrect or ambiguous → False.

1.c. Concept tag check (True/False):
Each model step includes essential mechanistic ideas (“most key concept tags”).
Mark True only if:

The same idea is conveyed for all “most key concept tags” in the matching student step semantically. So, a paraphrase with the same chemical meaning → True
(e.g., “good leaving group [Cl-]” in “most key concept tags” ≈ “departure of stable chloride species” in matching step from student answer)

Mark False if:
- The “most key concept tags” appears only in a different step
- The “most key concept tags” is missing, unclear, or incorrect
- If there is any uncertainty whether the concept is conveyed → mark False.

The same wording must convey all 'most key' concept tags in the model answer semantically between the matching step in the student answer and model answer (not necessarily word-for-word). If the student does not explicitly indicate the mechanistic idea, mark that check as False — do not infer understanding.
	Examples of semantic matches:
		“water as nucleophile” ≈ “attack by water”
		“loss of leaving group” ≈ “chloride leaves”
		“carbocation stability” ≈ “stable tertiary carbocation”

	If the meaning clearly corresponds, count it as present.

⚠️ Important:

Do not penalize differences in wording, order, or phrasing as long as the correct chemical meaning is preserved.

If the student omits an entire mechanistic step, uses an incorrect transformation type, or fails to mention any relevant concept, that step fails.

Step 2.  Categorization Logic - Assign Feedback Category

Final Category	Requirement
Category A	All 1.a, 1.b, and 1.c are True for every step
Category B	Any check is False for any step

---

## Output the category letter in the format:
Category: X

No additional commentary or reasoning.
