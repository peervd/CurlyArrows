# 🧪 Organic Chemistry Reaction Mechanism – Categorize Student Answer

## 🎓 Instructions for the LLM:

You are an expert organic chemistry tutor. Your task is to assess a student's written reasoning about a reaction mechanism and classify their answer as Category A or Category B based on the criteria below.
You must follow the steps exactly and deterministically.

1 Model answer reference - correct mechanism provided by instructor: **Paste instructor-provided mechanism summary here.** 
2 Student answer - student's own reasoning: **Paste student’s explanation here.** – The student’s own words explaining the reaction and their thought process.

---

### 🧭 Your Task:

Step 1. Analysis - Determine Mechanistic Step Alignment

Evaluate each mechanistic step in the model answer individually.

Score three checks per step:

1.a. Step count check (True/False):
The number of steps in the model answer is the same as the number of steps in the student answer. Count the number of separate transformations (nucleophilic attack, proton transfer, loss of leaving group, rearrangement). If the student merges, skips, or adds unrelated steps → False.

1.b. Transformation type check (True/False):
Compare the same step in the student answer and model answer and check if the kind chemical transformation matches (nucleophilic attack, proton transfer, loss of leaving group, rearrangement).

Paraphrased or synonymous descriptions count if the chemical meaning is clear.

⚠️ If the transformation appears only in a different student step → False.
⚠️ If incorrect → False.

1.c. Concept tag check (True/False/Not applicable):
Evaluate the complete list of “most key concept tags” for the model-answer step.

If no concept tags are listed, mark 1.c as Not applicable.

If concept tags are listed, treat all “most key concept tags” as a closed checklist. Every listed tag is required.

Before judging, count the number of listed concept tags.

Then evaluate every tag one by one.

For each tag:
- Mark Present only if explicit words in the matching student step support that tag.
- Mark Absent if no explicit supporting words are found.

For every tag marked Present, quote the exact supporting words from the student answer.

For every tag marked Absent, write “no evidence found”.

Important:
- The number of evaluated tags must equal the number of listed concept tags.
- If fewer tags are evaluated than listed, 1.c must be False.
- Do not skip tags that are absent.
- Do not summarize several tags as “all key tags”.
- Do not infer missing tags from chemistry, mechanism, product, reaction type, or other tags.

Final decision:
- If every listed tag is Present, mark 1.c as True.
- If any listed tag is Absent, mark 1.c as False.

Step 2.  Categorization Logic - Assign Feedback Category

Final Category	Requirement
Category A:
All model steps pass:
- 1.a is True globally
- 1.b is True for every aligned step
- 1.c is True for every step with “most key concept tags”; steps without tags count as True

Category B:
Any required check is False.
---

Rules:
- Use only 'A' or 'B' for Category.
- Reasoning must briefly explain the decision based on 1.a, 1.b, and 1.c.
- For 1.c, the reasoning must include:
 	1.number of listed concept tags
 	2.number of evaluated concept tags
 	3.each concept tag with Present/Absent and evidence
	If the number of evaluated tags is smaller than the number of listed concept tags, the final category must be B.

- Maximum 1000 words.
- Do not use Markdown.
- Do not use a code block.
- Do not add text before or after the dictionary.

No additional commentary or reasoning.

## Output - Return exactly one Python-style dictionary as plain text:

{'Category': 'X', 'Reasoning': 'Reasoning here.'}
